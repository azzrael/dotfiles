Vorbereitung unter Windows

Schritt 1 — Neue SSD einbauen

Baue die Lexar SSD 512GB ein. Sie ist ein PCIe 4.0 NVMe M.2 Laufwerk – auf dem ASRock B650M PG RIPTIDE gibt es mehrere M.2 Slots. Verwende idealerweise M2_2 oder M2_3 (nicht den primären Slot, in dem die Patriot-SSD mit Windows sitzt).

Schalte den PC aus, trenne den Strom, baue die SSD ein. Nach dem Einbau in Windows prüfen: Datenträgerverwaltung → die neue SSD sollte als "nicht initialisiert" erscheinen. Lass sie so – du brauchst sie nicht zu formatieren.
Schritt 2 — Bitlocker prüfen

Falls BitLocker auf der Windows-SSD aktiv ist: entweder deaktivieren oder den Recovery Key sichern. Dual Boot kann in seltenen Fällen BitLocker triggern.

Einstellungen → Datenschutz & Sicherheit → Geräteverschlüsselung
Schritt 3 — Fast Startup deaktivieren

Windows Fast Startup (Schnellstart) kann Probleme mit Linux verursachen, besonders beim Zugriff auf NTFS-Partitionen.

Systemsteuerung → Hardware und Sound → Energieoptionen
→ "Auswählen, was beim Drücken des Netzschalters geschehen soll"
→ "Schnellstart aktivieren" → DEAKTIVIEREN
Schritt 4 — Arch Linux ISO herunterladen

Lade das aktuelle Arch Linux ISO von der offiziellen Seite herunter:

https://archlinux.org/download/

Wähle einen deutschen Mirror (z.B. ftp.tu-chemnitz.de oder mirror.netcologne.de).

Optional: Signaturprüfung mit GnuPG oder Rufus integrierter Prüfsumme.
Schritt 5 — Bootbaren USB-Stick erstellen

Verwende Rufus (empfohlen für Windows):

  • Rufus herunterladen: rufus.ie
  • USB-Stick (min. 2GB) einstecken
  • Gerät: deinen USB-Stick wählen
  • Boot-Auswahl: das Arch-ISO wählen
  • Partitionsschema: GPT (da dein System UEFI nutzt)
  • Dateisystem: FAT32
  • Modus: "DD-Image schreiben" wenn Rufus fragt
  • Auf "Start" klicken
Achtung: Alle Daten auf dem USB-Stick werden gelöscht.
Schritt 6 — Windows vollständig herunterfahren

Nicht Neustart, sondern Herunterfahren – damit Fast Startup wirklich umgangen wird.

Start → Herunterfahren (nicht Neustart)

Wichtige BIOS-Einstellungen
Secure Boot
DISABLED — Arch Linux funktioniert ohne Secure Boot problemlos. Wer es will, kann es später mit sbctl einrichten, aber für den Anfang: aus.
CSM (Compatibility Support Module)
DISABLED — Du verwendest UEFI, nicht Legacy BIOS. CSM muss aus.
Fast Boot (BIOS-Fast Boot)
DISABLED — Nicht zu verwechseln mit Windows Fast Startup. Im BIOS ebenfalls deaktivieren.
SATA/NVMe Mode
AHCI — sollte schon so sein, aber prüfen.
Above 4G Decoding
ENABLED — für die RX 6700 XT empfohlen.
Resizable BAR (SAM)
ENABLED — AMD Smart Access Memory für bessere GPU-Performance unter Linux.
DOCP/XMP
ENABLED — Für beste RAM Performance.
Diese Einstellungen sind für deine Hardware optimal. AMD CPU + AMD GPU = native Linux-Treiberunterstützung, kein Proprietary-Chaos.

Speichere die BIOS-Einstellungen (F10).

GRUB Dual Boot Setup

Übersicht

GRUB auf der Lexon-SSD (Linux) erkennt via os-prober Windows auf der Patriot-SSD automatisch. Du brauchst Windows nicht anfassen.

Da beide SSDs getrennte Laufwerke sind, ist das Risiko für Windows sehr gering. GRUB schreibt nur auf die EFI-Partition der Linux-SSD.
Schritt 1 — os-prober aktivieren

In /etc/default/grub sicherstellen:

GRUB_DISABLE_OS_PROBER=false
Schritt 2 — Windows-Partition prüfen
lsblk -f

Du solltest die Patriot-SSD sehen, z.B. als /dev/nvme0n1 mit NTFS-Partitionen.

Falls die Windows-EFI-Partition nicht automatisch erkannt wird:
sudo mount /dev/nvme0n1p1 /mnt/windows-efi (Pfad anpassen)
Schritt 3 — GRUB Config neu generieren
sudo os-prober
sudo grub-mkconfig -o /boot/grub/grub.cfg

Die Ausgabe von os-prober sollte etwa zeigen:

/dev/nvme0n1p2@/efi/Microsoft/Boot/bootmgfw.efi:Windows Boot Manager:Windows:efi
Schritt 4 — GRUB anpassen (optional)

In /etc/default/grub:

GRUB_TIMEOUT=5           # 5 Sekunden Wartezeit
GRUB_DEFAULT=0           # Standardmäßig Arch booten
GRUB_TIMEOUT_STYLE=menu  # Menü immer anzeigen

Nach Änderungen immer:

sudo grub-mkconfig -o /boot/grub/grub.cfg
GRUB Theme (optional)

Ein schönes GRUB Theme via AUR:

yay -S grub-theme-vimix    # oder catppuccin-grub-theme-git

Theme in /etc/default/grub setzen:

GRUB_THEME="/usr/share/grub/themes/vimix/theme.txt"
sudo grub-mkconfig -o /boot/grub/grub.cfg
BIOS Boot Order

Im BIOS die Lexar-SSD (Linux) als erstes Boot-Gerät setzen. GRUB zeigt dir dann bei jedem Start das Menü mit Arch Linux und Windows zur Auswahl.

Alternativ: Windows direkt über BIOS Boot Menu (F11) booten, ohne die Boot Order dauerhaft zu ändern.
Zusammenfassung Boot-Flow
PC einschalten
    → UEFI lädt GRUB von Lexar-SSD EFI
    → GRUB Menü (5 Sek.)
        ├── Arch Linux  → Kernel auf Lexar-SSD
        └── Windows     → Windows Bootmanager auf Patriot-SSD
